# jev-ui

用意しておいた部品の組み方と型（画面案）を2枚ずつ見せて、どちらかを選んでもらい（評価）、一言を添えてもらう。Jev がその評価をもとに部品ごとの大きさと型を判断して、次の2枚を組むプロト。続けるうちに自分仕様のホーム画面が育つかを確かめる。言葉は [GLOSSARY.md](./GLOSSARY.md) に従う。

## 動かす

Node 22.9 以上。

```sh
cd jev-ui
npm ci
echo 'TYPESAFE_API_KEY=...' > .env   # キーはサーバー側だけで使う
npm start                            # http://localhost:3005
```

- ← で左、→ で右を選ぶ。Shift を押しながら選ぶと「これ！」（画面案ごとのボタンでも同じ）
- 一言は画面の下の欄に打つ。打たなくても進める。Enter で確定してから選ぶ
- 30 回で1回の試しが終わり、集計が出る

`http://localhost:3005/?auto` を開くと、自動で 30 回選んで集計まで出す（動作確認用）。サーバーを起動したまま `npm run autoswipe` でも同じことを端末で行う。

## しくみ

1. 画面案は、部品ごとの大きさ（出さない／小／中／大）と、型の4軸（並べ方: 1列／2列／タイル3列、余白: 詰める／ふつう／広い、文字: 小／ふつう／大、地: 白地／黒地）の組み合わせ
2. 選ぶたびに、部品7個と型の4軸の Choice をまとめて1リクエストで Jev（`jev-latest`）に聞く。state はこれまでの2枚の構成、どちらが選ばれたか、これ！、一言の一覧
3. 次の2枚のうち1枚は Jev の案（各質問で一番確率の高い答え）。もう1枚は寄り道の案で、確率を一様な確率と半々に混ぜてならし、サイコロを振って Jev の案から2か所以上（うち1か所以上は型）を変える。左右はランダム
4. 最初の1組は履歴が無いので、Jev に聞かず両方とも一様なサイコロで振る
5. 部品の並び順はコードで決める（大きいものを上、同じ大きさは部品の定義順）
6. 選んだほう・Jev の案が左右どちらだったか・これ！・一言・呼び出し時間・確率を `logs/<試しの id>.jsonl` に追記する

| ファイル            | 役割                                       |
| ------------------- | ------------------------------------------ |
| `lib/parts.js`      | 部品と大きさの定義                         |
| `lib/kata.js`       | 型の4軸の定義                              |
| `lib/jev.js`        | Jev に渡す state と Choice                 |
| `lib/screen.js`     | Jev の案・寄り道の案と並び順                           |
| `lib/trial.js`      | 1回の試しの進行                            |
| `lib/summary.js`    | 完了条件の集計                             |
| `public/parts.js`   | 部品の見た目（小・中・大）と型                 |
| `public/content.json` | 部品の中身（ダミー）                     |
