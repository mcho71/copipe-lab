# jev-ui

用意しておいた部品の組み方（画面案）を1枚ずつ見せて、スワイプと一言で評価してもらい、Jev がその評価をもとに部品ごとの大きさを判断して、次の画面案を組むプロト。続けるうちに自分仕様のホーム画面が育つかを確かめる。言葉は [GLOSSARY.md](./GLOSSARY.md) に従う。

## 動かす

Node 22.9 以上。

```sh
cd jev-ui
npm ci
echo 'TYPESAFE_API_KEY=...' > .env   # キーはサーバー側だけで使う
npm start                            # http://localhost:3005
```

- → 好き、← いまいち、↑ これ！（矢印キー、下のボタン、マウスのドラッグ）
- 一言は画面の下の欄に打つ。打たなくても進める。Enter で確定してからスワイプする
- 30 スワイプで1回の試しが終わり、集計が出る

`http://localhost:3005/?auto` を開くと、自動で 30 スワイプして集計まで出す（動作確認用）。サーバーを起動したまま `npm run autoswipe` でも同じことを端末で行う。

## しくみ

1. 最初の画面案は Jev に聞かず、一様な確率で組む
2. スワイプのたびに、部品ごとの Choice（出さない／小／中／大）を全部品ぶん1リクエストで Jev（`jev-latest`）に聞く。state はこれまでの画面案の構成と評価、一言の一覧
3. 返ってきた確率で部品ごとにサイコロを振って次の画面案を組む。並び順はコードで決める（大きいものを上、同じ大きさは部品の定義順）
4. 評価・一言・呼び出し時間・確率を `logs/<試しの id>.jsonl` に追記する

| ファイル            | 役割                                       |
| ------------------- | ------------------------------------------ |
| `lib/parts.js`      | 部品と大きさの定義                         |
| `lib/jev.js`        | Jev に渡す state と Choice                 |
| `lib/screen.js`     | サイコロと並び順                           |
| `lib/trial.js`      | 1回の試しの進行                            |
| `lib/summary.js`    | 完了条件の集計                             |
| `public/parts.js`   | 部品の見た目（小・中・大）                 |
| `public/content.json` | 部品の中身（ダミー）                     |
