# Jev で UI を組み替えるインタラクティブ UI

用意しておいた部品の組み方を、スワイプと一言で評価していき、Jev がその評価をもとに次の画面案を選んで、自分仕様の画面に育てていく試作。

## Language

**部品**:
前もって用意しておく UI のかけら。Jev は部品を作らず、選ぶだけ。
_Avoid_: コンポーネント, ウィジェット

**組み替え**:
どの部品を、どこに、どの大きさで出すかを変えること。中身の入れ替えと、部品の生成は含まない。
_Avoid_: 生成, おすすめ, パーソナライズ

**中身**:
部品に流し込む情報そのもの（予定、商品など）。組み替えの対象ではない。
_Avoid_: コンテンツ, 餌

**画面案**:
部品の組み方の一つ。利用者が好き／いまいちを評価する単位。
_Avoid_: バリアント, パターン, カード, 餌

**ホーム画面**:
育てる対象の画面。毎朝開く想定で、今日の予定やタスクなどの部品を並べた1枚。
_Avoid_: ダッシュボード, トップページ

**評価**:
画面案に対する利用者の反応。好き／いまいち／これ！の3つ。
_Avoid_: レーティング, いいね, フィードバック

**これ！**:
評価のうち最上位のもの。「たまにとても美味しい」画面案に当たったことを表す。
_Avoid_: スーパーライク, お気に入り

**一言**:
利用者が画面案に添える、短い自然文の感想（例:「もっとスッキリ」）。
_Avoid_: プロンプト, フィードバック, コメント

**Jev 必須**:
その判断を if 文で実用的に書けず、かつ Jev の即応性か、型と確率で返る形式が体験に効いている状態。案を採るかどうかの基準。
_Avoid_: Jev でなきゃできない

**試し**:
画面案を決まった枚数（30 枚）続けて評価する1回分。ホーム画面が育ったかを集計する単位。
_Avoid_: セッション, ラウンド
